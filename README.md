# 信号检测论交互式实验 ——「海空战备防空雷达站」

工程心理学 · 作业一。纯前端（HTML + CSS + 原生 JavaScript）实现的信号检测论（SDT）检测游戏：被试扮演夜间防空雷达站操作员，判断每一次回波是敌机还是杂波；一局结束后自动给出完整的 SDT 计算结果与决策风格分析。

## 一、如何运行

1. 打开文件夹 `第一次作业/`
2. 双击 `index.html`（Chrome / Edge / Firefox / Safari 均可）
3. 在左侧设定参数，点击「开始实验」或按 **空格键** 进入

无需 Node.js、Python、后端服务或任何外部库；不需要构建步骤，不依赖网络。

**操作**：`J` 或 `1` = 有信号，`F` 或 `2` = 无信号（也可直接点击按钮）。

## 二、评分点对应

### 01 场景与参数定义（15 分）

- **信号**：敌方低空突防目标的多普勒微弱回波；**噪音**：海杂波、降雨云团与大气电磁热噪。二者在参数页有明确定义。
- **先验概率 P(S)**：0.10 ~ 0.90 滑块可调（默认 0.50），分别模拟罕见突防与密集敌情。
- **四种结果的实际含义**：参数页给出 H / M / FA / CR 四格表及其对应的战备后果（拦截成功、防区破防、虚耗弹药、战备稳定）。

### 02 交互式检测游戏（35 分）

- **逐次试次**：试次表在开局时一次性生成并打乱，逐个呈现，符合心理物理学逐次判断的要求。
- **每局 ≥ 20 试次**：可选 20 / 30 / 50 试次。
- **刺激限时**：观测窗可选 1.5 / 3.0 / 6.0 秒；窗内扫描线匀速扫过 2 圈，回波随扫描线相位同步闪烁；窗末画面立即清空。
- **难度调节（d'）**：容易 d' ≈ 2.5 / 中等 d' ≈ 1.5 / 困难 d' ≈ 0.6。难度同时改变回波亮度与杂波亮度上限——困难档下杂波有可能比回波更亮，「亮点」不再等同于「有信号」。

> **关于限时**：限时作用在**刺激呈现**阶段（观测窗），判断阶段**不限时**，被试可以慢慢回忆、慢慢决定。这样既满足评分标准中「刺激限时」的要求，又避免把反应速度混进辨别力指标。

### 03 结果计算与展示（30 分）

- **混淆矩阵**：自动统计 H / M / FA / CR 的频数与百分比。
- **指标**：P(Hit)、P(FA)、d'、c、β、准确率，逐项列出公式与数值。
- **极端概率校正**：概率为 0 或 1 时按 Macmillan & Creelman 法则作 1/(2N) 半格校正，避免 probit 发散。
- **决策风格评定**：依 c 自动判为保守型 / 中立无偏型 / 宽松冒险型，并生成文字分析。
- 与「甲（谨慎型）」「乙（宽松型）」两种策略对照，说明同一段 P(S) 与代价结构下判定标准 c 应当偏向哪一侧。

### 04 代码规范可运行（20 分）

- 模块化拆分（见下节），核心算法均附注释。
- 不使用 ES module 与构建工具，`file://` 直接打开即可运行；`localStorage` 读写有 try/catch 兜底，隐私模式或 `file://` 受限时静默降级而不报错。

### 加分项

- **交互式概念可视化**：双正态分布图（随 d' 变化、c 滑块实时移动判定阈）与等辨别力 ROC 曲线（含被试本局实测操作点、AUC）。全部用 SVG 绘制。
- **多局数据对比 / 排行榜**：`localStorage` 持久化历次记录，按 d' 排名，可跨难度对比策略变化。
- **界面美感与场景代入**：雷达站战术荧光绿主题。雷达用纯 CSS 绘制——`repeating-radial-gradient` 距离环、`linear-gradient` 方位十字线、`conic-gradient` 扇形扫描线，杂波点各自带随机亮度与闪烁相位（模拟真实杂波的时间起伏）。**未使用 Canvas。**

## 四、几处实现说明

- **试次表预打乱**：先按 `nSignal = round(试次总数 × P(S))` 生成定量的信号/噪音列表再 Fisher-Yates 打乱，而不是每试次独立随机抽样。这样保证每局的信号数恰好符合先验，不会出现「整局没有信号」导致 P(Hit) 无定义的退化情况。
- **回波与扫描线的相位锁定**：回波的闪烁周期设为与扫描线旋转周期相同，并用负的 `animation-delay` 把它对齐到该方位角被扫到的瞬间。因为一个观测窗内固定扫过 2 圈，任意方位的回波至少闪亮 1 次。
- **雷达与图表都不用 Canvas**：雷达是 DOM + CSS 渐变/动画，图表是 SVG（viewBox 自适应缩放）。Canvas 在作业技术要求中是可选项（「可用 Canvas 绘制游戏画面」），故采用纯 CSS/SVG 实现，同时保留了逐帧动画与矢量缩放。
