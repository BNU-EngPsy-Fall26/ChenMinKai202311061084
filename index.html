情境设定

你是海空防空雷达站的操作员。屏幕上持续跳动的是杂波光点；偶尔会有低空突防敌机的微弱回波混在其中。你的任务是判断：这一次回波里，到底有没有敌机？

信号 (Signal)
低空高速突防敌机产生的微弱相干多普勒回波——比杂波更亮，但未必亮得明显。
噪音 (Noise)
海面杂波、气象云团与大气电磁热噪。它们本身就是忽明忽暗的亮点，因此"看到亮点"并不等于"有敌机"。

四种判断结果的实际含义

你的判断实际情况结果战备后果
有信号有敌机击中 (Hit)锁定目标，引导拦截成功
无信号有敌机漏报 (Miss)突防破防，造成防空缺口
有信号仅杂波虚警 (FA)误警，浪费拦截弹药与值班兵力
无信号仅杂波正确否定 (CR)成功剔除杂波干扰，继续保持警戒

注意：漏报与虚警的代价并不相同。后面你会看到，正是"代价不对称"决定了操作员应该把判定标准 c 放在哪里。

你的判断 实际情况

说"有" 击中 H = 0 虚警 FA = 0
说"无" 漏报 M = 0 正确否定 CR = 0

SDT 指标 —

击中率 P(Hit) — H / (H + M)
虚警率 P(FA) — FA / (FA + CR)
辨别力 d' — Z(Hit) − Z(FA)
判定标准 c — −½ · [Z(Hit) + Z(FA)]
似然比 β — exp(d' × c)
准确率 — (H + CR) / N

想一想：为什么光看"准确率"不够？

下面两位同学的准确率和你都是同一个数字，但他们的问题完全不同。把他们的 P(Hit)、P(FA) 和你自己的对照着看。

操作员P(Hit)P(FA)d'c准确率
甲（谨慎型）0.600.10≈ 1.8+0.520.75
乙（宽松型）0.900.40≈ 1.8−0.520.75
你—————

甲和乙的 d' 几乎一样——分辨能力相当；但 c 一正一负，说明甲的判定标准远比乙严格。准确率把这个差别完全掩盖了。把"能不能分清楚"（d'）与"敢不敢说有"（c / β）分开，正是信号检测论对工程心理学的核心贡献。
